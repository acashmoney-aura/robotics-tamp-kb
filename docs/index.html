What this graph is doing

This repo uses markdown frontmatter as the lightweight structure layer. Notes declare topics, entities, sources, and relations. A small mediator script builds a graph from that metadata without waiting for a full ontology/hydration setup.

  • markdown files stay human-editable
  • git remains the source of truth
  • packages, benchmarks, methods, and failure modes become graph nodes
  • research notes become structured systems maps instead of just bookmarks

Core thesis

The hardest part of modern dual-arm TAMP is the missing middle layer between symbolic plans and geometric execution: task-motion-scheduling.

To turn scattered robotics reading into a durable systems map that is searchable, inspectable in git, and easy to extend with daily research updates.

Geometry layer

Drake, IRIS, and GCS matter when the problem becomes how to summarize feasible regions before symbolic plans drift too far from reality.

LLMs in the loop

The repo’s current view: language models work best as interfaces and repair modules, not as the trust anchor for core planning.

Systematic study · CLAIRify

Best first implementation path

  1. Start with a PDDLStream-style formulation for interpretability.
  2. Make scheduling and shared-resource conflicts explicit.
  3. Use a fast motion backend to test synchronized candidates.
  4. Add execution recovery with behavior-tree-style fallbacks.
